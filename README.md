### 🧭 How I build

- 🎯 **Field-first** — if it doesn't work on a phone at a fuel station with patchy signal, it isn't done
- 📦 **Single-file by default** — one HTML file, libraries inlined, opens anywhere, survives corporate firewalls
- 🎨 **Clean & minimal** — professional enough for a PSU office note, nice enough that people *want* to use it
- 🔁 **Automate the repeat** — the second time I do a task by hand is the last
